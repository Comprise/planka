# planka — видимые предупреждения, классы файлов, один путь установки, журнал без содержимого

Дата: 2026-10-07. Дополняет `2026-10-07-planka-docs-design.md`.

## 1. Решения автора (2026-10-07)

- Предупреждения показываются полем `systemMessage` JSON-ответа хука при коде выхода 0. По документации
  Claude Code stderr хука с кодом 0 уходит только в debug-лог; `systemMessage` — общее поле всех событий
  («Warning message shown to the user») и совмещается с `additionalContext`, `decision: block` и
  `permissionDecision`. Выход с кодом 1 отвергнут: у `UserPromptSubmit` теряется напоминание.
- Три класса изменённых файлов: код, документация, прочее. Сверку документации запускает только код.
  Прочее и удалённые файлы показываются судье без запуска; список файлов ограничен.
- Один путь установки — маркетплейс: локально `claude plugin marketplace add ~/Projects/planka`,
  удалённо `claude plugin marketplace add Comprise/planka`; id `planka@planka`. Цели `make install` и
  `make uninstall` удаляются.
- `judge.log` хранит метаданные без проверенного содержимого: хук, вердикт, причина, фильтры,
  длительность, длина и SHA-256 содержимого, пути изменённых файлов. Размер ограничен ротацией в
  `judge.log.1`.

## 2. Вывод хука

`common.warn` копит строки `planka: …`; `common.emit` запоминает ответ хука (словарь); `common.run_hook`
после `main` пишет в stdout один JSON: ответ хука, если есть, плюс `systemMessage` — строки
предупреждений через перевод строки. Нет ни ответа, ни предупреждений — stdout пуст. stderr хуки не
пишут. Исключение в `main` даёт предупреждение «внутренняя ошибка» тем же каналом.

## 3. Классы файлов

`common.path_kind(relpath)` → `"doc"`, `"code"` или `"other"`. Документация — как прежде (`*.md`,
`README*`, `LICENSE*`, `context/`, `docs/` от корня). Код — расширение из `common.CODE_EXTS` или имя из
`common.CODE_NAMES` (`Makefile`, `Dockerfile`, `Justfile`, `Rakefile`, `Gemfile`). Остальное — прочее.
Каждое расширение с синтаксисом комментариев в `comments.py` входит в `CODE_EXTS`.

Содержимое для судьи: строки «путь — код|документация|прочее», удалённый файл с пометкой «удалён»;
не больше `MAX_LISTED = 100` строк, дальше «… и ещё N». «Без известного синтаксиса» — только
существующие файлы кода, у которых нет семейства комментариев.

## 4. Журнал

`log_event(..., content=…)` пишет `content_len` и `content_sha256` вместо текста. Перед записью при
размере файла ≥ `LOG_MAX_BYTES = 1 048 576` файл переименовывается в `judge.log.1`, прежний
`judge.log.1` заменяется.

## 5. Проверка

`make test`, `make validate`. Живая проверка автором: строка `planka: задайте comment_lang и doc_lang…`
видна в терминале при незаданных настройках; после установки из локального маркетплейса
`claude plugin list` показывает один `planka@planka`.

## 6. Допущения

- Показ `systemMessage` у `UserPromptSubmit`, `PreToolUse` и `Stop` взят из общего раздела документации;
  в разделах этих событий оговорок нет. Вживую не проверен.
- Длина списка `MAX_LISTED = 100` и порог `LOG_MAX_BYTES = 1 MiB` выбраны координатором.
