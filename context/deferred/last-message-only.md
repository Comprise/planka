# Судья видит только последнее сообщение

**Что не так.** `judge_stop.main` судит `last_assistant_message` из входа хука: сверка
документации, названная в более раннем сообщении той же реплики, судье не видна.

**Чем доказано.** Чтением `judge_stop.main`: содержимое судьи строится из `message` и
изменённых файлов.

**Верное решение.** Не записано.

**Почему отложено.** Долг, принятый автором, решение от 2026-10-07: «Судья видит только последнее
сообщение агента: сверка обязана быть в нём названа».
