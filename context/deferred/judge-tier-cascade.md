# Ярус модели судьи

**Что не так.** Настройка `judge_model` (`plugin/.claude-plugin/plugin.json`) по умолчанию — `session`: судья зовёт
модель сессии (`model_watch.py` запоминает её). В сессии на фронтире каждая проверка судьи — `judge_tool.py`,
`judge_stop.py`, `guard_memory.py` — идёт на фронтире. Замер 2026-10-10 покрыл судью вопроса и судью `Stop`; судья
плана, судья записи в память и фильтр «документация» судьи `Stop` не замерены.

**Чем доказано.** Замер на настоящих входах из транскриптов проекта: промпт собран функциями плагина с текущей
рубрикой (`prompts.stop_prompt`, `prompts.question_prompt`), вызов — `common.run_judge`, модели `opus` и `sonnet`, по 2
прогона, 86 случаев, разметка «нарушение есть / нет» по тексту правил одним разметчиком (две версии: исходная и после
сверки отказов). Доли по вызовам:

| Вид | Модель | Пропуск нарушений | Ложные отказы |
| --- | --- | --- | --- |
| вопрос | opus | 4/32 (12%) | 1/40 (3%) |
| вопрос | sonnet | 10/32 (31%) | 1/40 (3%) |
| `Stop` («варианты», «готово») | opus | 1/40 (3%) | 3/28 (11%) |
| `Stop` («варианты», «готово») | sonnet | 3/40 (7%) | 10/28 (36%) |

Каскад «sonnet, при отказе — opus»: на вопросе пропусков 12/32 (вердикт ok дешёвой модели окончателен), на `Stop` opus
вызывается в 47 из 68 проверок, медианное время 24 с вместо 13. По этим данным `judge_model` по умолчанию не менялось.

**Верное решение и цена.** Остаток замера: судья плана (`judge_tool.judge_plan`) и судья записи в память
(`guard_memory`) — тем же путём (`prompts.plan_prompt`, `prompts.memory_prompt` через `common.run_judge`, `opus` и
`sonnet`, по 2 прогона), когда в транскриптах наберётся не меньше ~10 настоящих вызовов каждого вида; фильтр
«документация» судьи `Stop` — со сбором входа судьи (снимок дерева на начало реплики) в момент вызова. Цена — прогон
настоящих моделей и разметка; по итогу — значение `judge_model` для этих видов.

**Почему отложено.** Настоящих входов нет: в транскриптах ни одного `ExitPlanMode` и ни одной записи в память, в
`judge.log` нет записей `plan` и `memory`; вход фильтра «документация» из транскрипта не восстановить. Вес низкий:
затраты, а не корректность.
