# Комментарии только известных синтаксисов

**Что не так.** `comments.extract` извлекает строки комментариев только для расширений из
`comments._KNOWN`; остальные файлы кода передаются судье списком «судятся по самоотчёту»
(`prompts.render_docs_content`), и их комментарии судья не видит.

**Чем доказано.** Чтением `comments.extract`.

**Верное решение.** Не записано.

**Почему отложено.** Долг, принятый автором, решение от 2026-10-07: «Извлечение комментариев знает
перечисленные синтаксисы; язык с иным синтаксисом судится по самоотчёту».
