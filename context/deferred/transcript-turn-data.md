# Данные из недокументированного транскрипта

**Что не так.** `common.read_transcript` берёт из транскрипта (`transcript_path`) все сообщения агента за реплику
(судья `Stop`) и реплики автора — текущую и прежние (блок `<author>` судей и судья записи в память), а формат
транскрипта Claude Code не документирует. Модель сессии оттуда же — запасной источник: основной — события
`SessionStart` и `PostModelSwitch` (`model_watch`, `context/architecture.md`, «Судья»), транскрипт нужен, пока ни одно
событие модели не пришло (сессия начата до установки плагина, версия Claude Code до 2.1.251, `SessionStart` без
`model`). Отсев записей `isSidechain`, `isMeta`, `tool_result`, служебных записей по `origin.kind`
(`task-notification`, `peer`), вложений `queued_command` с репликой человека посреди хода, ответов автора при
отклонении инструмента (`toolDenialKind`, `permissionDecision.source`, `userFeedback`) и моделей вида `<synthetic>`
опирается на тот же формат; записи `<synthetic>` в транскриптах автора не встречались, отсев — допущение. Корпус форм
— `tests/fixtures/transcript-shapes.jsonl`.

**Чем доказано.** Документация хуков (code.claude.com/docs/en/hooks.md): сообщений реплики во входе `Stop` нет —
только `last_assistant_message`; ни одно событие не передаёт сообщения реплики и реплики автора за сессию. Модель
сессии документирована: `model` во входе `SessionStart` («Claude Code doesn't always include it») и `to_model` во входе
`PostModelSwitch` (v2.1.251+, срабатывает и на смены, которые Claude Code делает сам). Формат транскрипта проверен на
транскриптах автора 2026-10-07 и 2026-10-08 (Claude Code 2.1.293). В бинарнике Claude Code 2.1.294 общий вход хука —
`session_id`, `transcript_path`, `cwd`, `scratchpad_dir`, `prompt_id`, `permission_mode`, `agent_id`, `agent_type`,
`effort`; сообщений реплики нет (`strings`, 2026-10-08).

**Верное решение и цена.** Документированные поля входа хука с сообщениями реплики и репликами автора. Цена — зависит
от Claude Code: таких полей нет. Модель из транскрипта можно убрать, когда события модели станут обязательными для
поддерживаемых версий; цена — сессии, начатые до установки плагина, идут на модели `claude` по умолчанию с
предупреждением.

**Почему отложено.** Внешний предел. Смена формата не ломает проверки: модель не найдена ни в состоянии, ни в
транскрипте — судья без `--model` с предупреждением; сообщения не найдены — судья видит `last_assistant_message` с
предупреждением.
