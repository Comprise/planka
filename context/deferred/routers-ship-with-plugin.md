# Роутеры плагина уходят пользователям

**Что не так.** `plugin/planka/CLAUDE.md` и `plugin/rules/CLAUDE.md` лежат внутри `plugin/`, а
маркетплейс отдаёт пользователям каталог `plugin/` целиком (`"source": "./plugin"` в
`.claude-plugin/marketplace.json`). Это документация разработки, пользователю она не нужна.
Claude Code `CLAUDE.md` из каталога плагина в контекст не загружает, поэтому вреда нет, есть
лишний груз в поставке.

**Чем доказано.** Чтением `.claude-plugin/marketplace.json` и `ls plugin/planka plugin/rules`.
Что Claude Code не загружает `CLAUDE.md` плагина, следует из предупреждения
`claude plugin validate` до переноса в `plugin/`: «CLAUDE.md at the plugin root is not loaded as
project context». Для вложенных каталогов плагина это не проверено.

**Верное решение и цена.** Держать роутеры вне поставляемого каталога: правило
`plugin/rules/docs.md` разрешает роутер поставляемого каталога класть рядом с ним, а не внутрь.
Цена — правка правила, которое действует во всех проектах пользователей; перенос двух роутеров;
обновление ссылок на них в `CLAUDE.md` и `context/`.

**Почему отложено.** Решение меняет общее правило `docs.md` — выбор автора; вопрос задан, ответа нет.
