# Тексты установщика code-review-graph на английском

**Что не так.** `.claude/skills/*/SKILL.md` (`debug-issue`, `explore-codebase`, `refactor-safely`,
`review-changes`) и раздел `## MCP Tools: code-review-graph` в `CLAUDE.md` — на английском, при правиле
`CLAUDE.md` «Комментарии в коде и документация для агента — на русском». Тексты созданы установщиком
code-review-graph; агент их сам не правит (ядро, «Границы»: генерируемое и настройки агента).

**Чем доказано.** Чтением `.claude/skills/*/SKILL.md` и раздела `CLAUDE.md` между метками
`<!-- code-review-graph MCP tools -->` и `<!-- /code-review-graph MCP tools -->`.

**Верное решение и цена.** Либо перевести, либо записать в `CLAUDE.md` исключение «тексты, созданные
установщиками инструментов, не переводятся»: перевод затирается следующей установкой, поэтому
рекомендуется исключение. Цена — минуты правки.

**Почему отложено.** Выбор между переводом и исключением — за автором; `.claude/` правит только автор.
Вес низкий: язык текста не меняет поведение плагина и не уходит пользователям (`plugin/` их не
содержит).
