# Судья переживает хук вне Linux

**Что не так.** `common.run_judge` ставит `PR_SET_PDEATHSIG` (`common._die_with_hook`) только на Linux.
На macOS и других POSIX хук, убитый по таймауту или прерыванием, оставляет работающий `claude -p`:
судья в своей группе процессов (`start_new_session=True`) и сигнал хука его не достаёт.

**Чем доказано.** Чтением `common.run_judge`: `preexec_fn` задан при `sys.platform.startswith("linux")`.
Тест `JudgeDiesWithHookTest` на Linux проходит, на других платформах пропускается.

**Верное решение и цена.** Сторож за родителем: судья запускается обёрткой, которая опрашивает
`os.getppid()` или держит pipe с хуком и убивает группу судьи при закрытии pipe. Цена — отдельный
процесс-обёртка на каждый вызов судьи и тест на него.

**Почему отложено.** Решение вне Linux проверить негде: в окружении разработки есть только Linux.
