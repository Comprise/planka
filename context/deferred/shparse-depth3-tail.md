# Разбор shell: хвост расхождений с bash на глубокой вложенности

**Что не так.** `plugin/planka/shparse.py` на формах генератора глубины 3 (`tests/tools/bashdiff.py --depth 3`) теряет
команды, которые bash исполняет: 0–3 формы на 20 000. Найденные формы (зерно 13, глубина 3, номера 7023, 11307,
15333) — подстановка `${| …; }` внутри образца `${HOME/…}`, `${HOME//…}` в теле heredoc или в `$(( … ))`; текст —
`bashdiff.generate(13, N, depth=3)[0]`. Ещё два остатка: цепочка вложенных подстановок, где слова скобок массива с `\`
делятся при чтении и при раскрытии по-разному (`$(a=(\'y) ; … ; b=(\'))` уровень в уровне), разбирается за
квадратичное время — 200 уровней (около 7 КБ) около 13 с, как и в bash (`xparse_dolparen` перечитывает вложенный
текст); синтаксическая ошибка подстановки при раскрытии в bash обрывает остаток командной строки, дерево её команды
сохраняет (ложный отказ, не пропуск).

**Чем доказано.** Фаззер `--target parser`, по 20 000 форм: глубина ≤ 2 — ноль потерь на зёрнах 1, 5, 11, 13;
глубина 3 — ноль на зёрнах 1, 2, 3, 5, 7, 11 и 3 потери на зерне 13. Квадратичность и строгость — замеры и прогоны
bash в песочнице исполнителя волны 1 (отчёт), координатор их не перепроверял.

**Верное решение и цена.** Круги правок по причинам по исходнику bash 5.3, пока фаззер на 8 зёрнах и глубинах 1–3 не
даст ноль; для цепочки повторного раскрытия — линейный алгоритм или предел работы разбора с сомнением детектора сверх
предела. Цена — 35–75 минут на круг, число кругов неизвестно: каждый новый генератор находил следующий класс.

**Почему отложено.** Решение автора 2026-10-09: хвост глубины 3 принять долгом и идти по плану. Формы глубины 3 в
настоящих командах корпуса не встречаются (`tests/fixtures/bash-transcripts.jsonl`, `bash-commands.jsonl`
разбираются без потерь по проверке исполнителя). Вес средний: обход детектора экзотической записью и возможный
таймаут хука на специально собранной цепочке.
